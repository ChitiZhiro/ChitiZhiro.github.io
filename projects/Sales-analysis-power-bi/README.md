# Electrical and Mechanical Sales Analysis – Power BI

## Project Overview

This project uses Microsoft Power BI to analyze electrical and mechanical sales data through interactive dashboards and visual reports.

## Objectives

- Analyze sales performance using interactive visualizations.
- Identify trends and patterns in the available sales data.
- Present business insights in a clear, user-friendly dashboard.

## Tools Used

- Microsoft Power BI
- DAX

## Project Files

- `Elec. and Mech sales.pbix` – Power BI report file.
- `Screenshots/` – Dashboard screenshots for preview.
