# E-commerce Sales Analysis using MySQL

## Project Overview
This project analyzes e-commerce data using MySQL to extract business insights from customer, order, and product datasets. It explores sales performance, customer purchasing behavior, payment methods, and product trends using practical SQL queries.

## Objectives
- Analyze monthly revenue and average order value.
- Evaluate customer spending and repeat-customer behavior.
- Identify customers with no orders and their latest purchases.
- Analyze month-over-month revenue growth and cumulative sales.
- Identify top-performing products by category.

## Tools & Technologies
- MySQL
- SQL

## SQL Concepts Used
- Aggregate Functions and GROUP BY
- JOINs and Subqueries
- WHERE and HAVING
- Common Table Expressions (CTEs)
- Window Functions: LAG, ROW_NUMBER, DENSE_RANK
- Date Functions and Revenue Calculations

## Key Takeaways
Applied SQL techniques to analyze sales trends, customer behavior, and product performance, strengthening practical querying and analytical problem-solving skills.
